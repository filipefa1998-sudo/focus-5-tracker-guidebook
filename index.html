🔥
Streak badge — Shows consecutive months with activity logged. Builds accountability.
🔴

📋 Plan Column

Every person in the tracker has a Plan column — the four fields that turn the tracker from a scoreboard into a working tool. This is where you set ownership and next steps.

👤
Assign To (single dropdown)
One dropdown handles both the leader (shown in This Week and Action Board) and the organization (used in KPI reports). No duplicate fields.
⚡ EQ President 🌸 RS President 📖 Ward Missionaries 👔 Full-time Missionaries 🏛️ Bishop 🎯 YM President ⭐ YW President
📅
Next Contact Date
Date picker. Sets when this person should next be contacted. Drives the This Week tab — overdue dates turn red, this week turns yellow.
📝
Next Action
Free text field. e.g. "Invite to Thursday BBQ", "Follow up on lesson 2", "Check in about baptism date"
✅
Mark Contacted
One-click button that stamps today's date as the last contact. When a date exists, the button turns green and shows "Last: MM-DD". Used by Action Board to calculate staleness.

📋 This Week Tab

Your Sunday working document. Opens to every person sorted by urgency — overdue contacts at the top in red, then this week in yellow, upcoming in green, and no date set in gray. The tab shows a badge count of how many need action.

🔴 Overdue
Next Contact Date has passed. Contact is late. These always show first.
🟡 Due This Week
Contact date falls within the next 7 days. Act before it becomes overdue.
🟢 Upcoming
Contact date is more than 7 days out. On your radar but not urgent yet.

🔍 Tab Filter

Use the filter buttons in the header to narrow the view:

Ward missionaries can filter to Investigators only. EQ President can filter to Returning only. Ward Mission Leader can see All.

⚡ Quick Actions on Each Card

✅
Mark Contacted — Stamps today's date. Clears the urgency. Card moves to Upcoming or falls off the due list.
📅
Inline date picker — Change the next contact date right on the card without going back to the tracker table.
📱
Send Summary — Generates a pre-written WhatsApp/iMessage message listing every overdue and due-this-week contact with their assigned leader and next action. One tap to share.

🗂️ Action Board

The Sunday war-room view for ward council. Every person is automatically sorted into one of four columns based on their current status. No manual sorting needed — the app decides.

How Cards Are Auto-Sorted

🌱 New
Zero activities ever logged. Has never been contacted. Needs a first step.
🔄 In Progress
Has logged activities and was contacted within the last 30 days. Actively engaged.
⚡ Needs Attention
Has history, but no contact logged in 30+ days. Falling through the cracks — act now. Smart fallback: if no Mark Contacted date exists, uses last month with logged activity as a proxy.
🏆 Milestone Hit
Baptism date set (BD) or baptism completed (B/C indicator logged). Moved to Covenant Path next.

What's On Each Card

🔥
Streak badge — consecutive months with activity. e.g. "🔥 3mo"
👤
Assigned leader or red "Unassigned" badge if empty
📝
Next action text — pulled from Plan column
🏅
Top indicator — most frequently logged activity type
✓
This month count — activities logged this month
🕐
Days since contact — e.g. "12d ago"
🗂️ Action Board — Interactive Cards auto-sort based on activity and contact history

🎉 Ward Events Calendar

Shared calendar synced in real-time. Events are visible to everyone with the app link. Use it to plan which ward activities to invite investigators to.

📅 Adding an Event

📌
Event Name — e.g., "Ward BBQ", "Youth Talent Show", "Baptism Service"
📅
Date — Uses safe local date parsing (no off-by-one timezone bug)
⏰
Time — optional start time
📍
Location — building, address, etc.
🏷️
Event Type — Church Activity, Social, Sports, Service, Family, Scripture Study, Spiritual, Youth Activity
✨
"Great for inviting investigators" checkbox — marks the event with a ✨ badge everywhere it appears

👁️ Two Views

📅 Calendar View
Monthly grid. Click any day to add an event on that date. Events shown as color-coded pills by type. Click any event pill to edit.
📋 List View
Chronological list split into Upcoming (sorted soonest first, countdown badge: "3 days") and Past (last 8 shown). Click any event to edit or delete.
📱 Share Button — Each event has a Share button that uses the device's native share sheet (WhatsApp, iMessage, etc.) to send event details. Falls back to clipboard copy.

Best Practices

How to get the most out of this tool

☀️

Sunday Routine

After sacrament — open This Week, mark everyone contacted, set next contact dates for the coming week. Takes 5 minutes.

👥

Ward Council Prep

Before council — pull up Action Board. Walk the four columns left to right. ⚡ Needs Attention names get a quick plan assigned before the meeting ends.

📝

Write Real Next Actions

Don't leave the Next Action field empty. "Follow up" is not an action. "Call Sione about the BBQ Thursday" is. Specific = done.

🔥

Build Streaks

The 🔥 streak badge is a quiet accountability tool. When a person has 3+ months of consecutive activity, people don't want to break it — use that psychology.

📤

Export Weekly

Click 📥 Export every Sunday. Save the JSON backup to Google Drive or email it to yourself. Firebase is reliable, but local backups are your insurance.

🇹🇴

Use Lea Tonga

Toggle the 🇹🇴 Lea Tonga button for full Tongan translation. 200+ UI strings translated. Useful when presenting in ward council or sharing with Tongan-speaking members.
